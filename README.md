                                                                  🦖 Arduino Dino Game
                                    A simple Google Dinosaur-style game developed in C++ for Arduino Uno
Components Used
* 1x Arduino Uno
* 1x 16x2 LCD Display
* 1x Push Button
* Potentiometer and Breadboard
  Features
* Custom pixel sprites for the Dinosaur and Cactus.
* Non-blocking jump mechanics using `millis()`.
* Real-time Score system.
* Game Over screen with button restart functionality.

link of the demo and wiring: https://wokwi.com/projects/470366053058804737
